KHL AI: Season Simulator

Интерактивный симулятор сезона КХЛ 2026/27 на Python (PySide6) с тёмной темой. Учебный проект: я пишу код сам, с наставником в лице Claude.

Возможности (план)
Календарь сезона КХЛ 2026/27
Турнирная таблица, статистика команд, история матчей
Ручной ввод результатов (после подтверждения не редактируются)
Учебные прогнозы с аналитическим обоснованием (максимум 3 в день)
Плей-офф и Кубок Гагарина
Сохранение прогресса (SQLite)
В будущем: ML-модуль для анализа статистики и качества прогнозов
Технологии
Python
PySide6 (Qt for Python)
SQLite (позже)
Структура проекта
khl_Ai/
  main.py      # запуск и проверки
  models.py    # классы Team, Match
  data.py      # команды и расписание
  storage.py   # сохранение
  ui.py        # окно и меню (PySide6)
  ml.py        # будущий ML-модуль
learning.py    # тетрадь для тренировки
Запуск
pip install PySide6
python khl_Ai/ui.py
